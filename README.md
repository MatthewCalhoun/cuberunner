# Cube Runner

A 3D game where you control a cube and avoid obstacles, built with Three.js.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start the local server:
```bash
npm start
```

3. Open your browser and navigate to `http://localhost:8000`

## How to Play

- Control the red cube to avoid obstacles
- Score points by surviving longer
- Game ends when you hit an obstacle

## Development

The game is built using:
- Three.js for 3D graphics
- Vanilla JavaScript
- HTML5 and CSS3

## Project Structure

- `index.html` - Main game page
- `js/game.js` - Game logic and Three.js setup
- `css/style.css` - Game styling
- `package.json` - Project dependencies
